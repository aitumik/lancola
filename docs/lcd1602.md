# lcd1602: 16x2 I2C LCD

    mpremote mip install github:aitumik/lancola/drivers/lcd1602

## Wiring

| LCD backpack | ESP32 |
|---|---|
| GND | GND |
| VCC | 5V |
| SDA | 21 |
| SCL | 22 |

Turn the blue contrast screw on the back if the screen lights up but shows nothing.

## Usage

```python
from lcd1602 import LCD

lcd = LCD()                     # LCD(scl=22, sda=21, addr=0x27, freq=100000)
lcd.write("Hello\nWorld")       # \n moves to the second line
lcd.move_to(10, 1)              # column 0-15, row 0-1
lcd.write("!")
lcd.clear()
lcd.backlight(False)
```

## API

| Method | What it does |
|---|---|
| `LCD(scl=22, sda=21, addr=0x27, freq=100000)` | Set up and clear the screen |
| `write(text)` | Write at the cursor. Up to 2 lines, 16 characters each |
| `move_to(col, row)` | Move the cursor |
| `clear()` | Blank the screen, cursor to 0,0 |
| `home()` | Cursor to 0,0 without clearing |
| `backlight(on=True)` | Backlight on/off |
| `scan()` | Print I2C addresses found (expect `0x27` or `0x3f`) |

## Troubleshooting

- `scan()` shows nothing: check power and that SDA/SCL aren't swapped.
- `scan()` shows every address from `0x08` to `0x77`: SDA is held low.
  The wire is on the wrong pin, or the LCD isn't powered.
- Address is `0x3f`: use `LCD(addr=0x3f)`.
- Garbled text: try `freq=100000` (the default) with short wires.
