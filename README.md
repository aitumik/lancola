# lancola

MicroPython drivers for the ACEBOTT ESP32 Basic Starter Kit.

## Install

Everything:

    mpremote mip install github:aitumik/lancola

One driver:

    mpremote mip install github:aitumik/lancola/drivers/lcd1602

From the Thonny shell (board on Wi-Fi):

    import mip
    mip.install("github:aitumik/lancola")

## Drivers

lcd1602

Example programs are in `examples/`.
